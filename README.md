# The House Café — Premium Website V2

نسخة محسّنة فعليًا داخل ملفات الموقع، وتشمل نظام شعار أنظف وخطوط عربية مرتبة.

## ملفات الشعار
- `assets/logo-primary.png` الشعار الكامل بخلفية شفافة للاستخدام على الخلفيات الفاتحة.
- `assets/logo-white.png` الشعار الأبيض بخلفية شفافة للخلفيات الداكنة.
- `assets/logo-mark.svg` رمز الشعار بصيغة SVG.
- `assets/logo-mark-white.svg` الرمز الأبيض بصيغة SVG.

## نظام الخطوط
- Readex Pro للعناوين العربية الرئيسية.
- IBM Plex Sans Arabic للنصوص والقوائم والأزرار.
- Manrope للنصوص الإنجليزية الصغيرة.


## التعديل الأخير
تم اعتماد الشعار الرسمي الكامل داخل الهيدر والفوتر، مطابقًا لملف `assets/logo-primary.png`.


## الشعار المعتمد النهائي
تم وضع الشعار الدائري البرتقالي المرفق نفسه، مع الورقة البيضاء والحلقتين البيضاوين، في الهيدر والفوتر والكوب والخريطة وأيقونة الموقع.
